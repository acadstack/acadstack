# Face Recognition Service
This service performs the tasks related to face recognition.
It is mainly used for marking students' attandance in a classroom
by taking photos of the class and uploading to the AcadStack portal.

You can easily use this service for other face recognition tasks too.
This service provides generic APIs for detecting faces, computing face
vectors, marking faces in photos, etc.

It makes use of the popular library for face recognition:
https://github.com/ageitgey/face_recognition
